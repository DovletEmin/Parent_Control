# Android Build Instructions / Инструкции по сборке Android APK

## Требования

1. **Android Studio** (последняя стабильная версия — Ladybug или новее)  
   Скачать: https://developer.android.com/studio

2. **JDK 17** — идёт в комплекте с Android Studio

3. **Минимум 8 ГБ RAM** (рекомендуется 16 ГБ)

---

## Шаг 1: Установка Android Studio

1. Скачайте Android Studio с сайта выше
2. Запустите установщик, выберите «Standard» установку
3. Дождитесь скачивания Android SDK, Build Tools, платформ
4. После установки откройте Android Studio

---

## Шаг 2: Открытие проекта

1. В Android Studio: **File → Open**
2. Выберите папку `android/` (ту, где лежит `settings.gradle.kts`)
3. Нажмите **OK**
4. Дождитесь окончания Gradle sync (прогресс внизу экрана)
   - При первом запуске это может занять 5–10 минут — скачиваются зависимости

> Если Gradle sync выдаёт ошибку об SDK — зайдите в **File → Settings → Languages & Frameworks → Android SDK** и установите **SDK 35** (Android 15)

---

## Шаг 3: Настройка адреса сервера

⚠️ **ВАЖНО**: По умолчанию приложение подключается к `http://10.0.2.2:8000` (для эмулятора).  
Для реального устройства замените адрес на IP вашего сервера.

### Вариант A: Для эмулятора (тестирование на ПК)
Ничего менять не нужно. `10.0.2.2` — это localhost вашего ПК из эмулятора.

### Вариант B: Для реального телефона
Откройте файл `android/app/build.gradle.kts` и найдите строку:

```kotlin
buildConfigField("String", "BASE_URL", "\"http://10.0.2.2:8000\"")
```

Замените на IP вашего сервера:

```kotlin
buildConfigField("String", "BASE_URL", "\"http://ВАШ_IP:8000\"")
```

Также откройте файл `Prefs.kt` и измените:

```kotlin
private const val DEFAULT_SERVER_URL = "http://10.0.2.2:8000"
```

на:

```kotlin
private const val DEFAULT_SERVER_URL = "http://ВАШ_IP:8000"
```

## Шаг 4: Сборка Debug APK

### Через Android Studio (рекомендуется):

1. Вверху выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**
2. Дождитесь окончания сборки (1–3 минуты)
3. Внизу появится уведомление **«Build APK(s) ready»** — нажмите **locate**
4. APK будет в: `android/app/build/outputs/apk/debug/app-debug.apk`

### Через командную строку:

```bash
cd android
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

---

## Шаг 5: Сборка Release APK (для постоянного использования)

### 5.1. Создайте ключ подписи

В терминале (PowerShell / Command Prompt):

```bash
keytool -genkey -v -keystore release-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias parentcontrol
```

Вас попросят ввести пароль и данные — запомните пароль!

### 5.2. Добавьте конфигурацию подписи

Откройте `android/app/build.gradle.kts` и добавьте блок `signingConfigs` внутри `android { }`:

```kotlin
android {
    // ... существующий код ...

    signingConfigs {
        create("release") {
            storeFile = file("../release-key.jks")
            storePassword = "ВАШ_ПАРОЛЬ"
            keyAlias = "parentcontrol"
            keyPassword = "ВАШ_ПАРОЛЬ"
        }
    }

    buildTypes {
        release {
            isMinifyEnabled = true
            isShrinkResources = true
            signingConfig = signingConfigs.getByName("release")
            proguardFiles(
                getDefaultProguardFile("proguard-android-optimize.txt"),
                "proguard-rules.pro"
            )
        }
    }
}
```

### 5.3. Соберите Release APK

```bash
cd android
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`

## Шаг 6: Установка на телефон

### Вариант A: Через USB (рекомендуется)

1. На телефоне включите **Режим разработчика**:
   - **Настройки → О телефоне → Номер сборки** — нажмите 7 раз
2. Включите **Отладка по USB**:
   - **Настройки → Для разработчиков → Отладка по USB** — включить
3. Подключите телефон по USB к компьютеру
4. В Android Studio вверху выберите ваше устройство из списка
5. Нажмите зелёную кнопку ▶️ (Run)

### Вариант B: Через файл APK

1. Скопируйте APK на телефон (через USB, мессенджер, облако)
2. На телефоне: **Настройки → Безопасность → Установка из неизвестных источников** — разрешите для файлового менеджера
3. Откройте APK и установите

## Шаг 7: Настройка разрешений на телефоне

После установки и первого запуска приложение попросит разрешения.  
Некоторые нужно дать вручную:

### Обязательные разрешения:
| Разрешение | Где включить |
|-----------|-------------|
| Местоположение (всегда) | Настройки → Приложения → Родительский контроль → Разрешения → Местоположение → Всегда |
| Статистика использования | Настройки → Специальный доступ → Статистика использования → Родительский контроль |
| Администратор устройства | Настройки → Безопасность → Администраторы устройства → Родительский контроль |
| Без ограничений батареи | Настройки → Приложения → Родительский контроль → Батарея → Без ограничений |
| Автозапуск (Xiaomi/Samsung) | Настройки → Приложения → Управление автозапуском → Родительский контроль |

### Для Samsung дополнительно:
- **Настройки → Обслуживание устройства → Батарея → Спящие приложения** — убедитесь, что «Родительский контроль» НЕ в списке спящих

### Для Xiaomi дополнительно:  
- **Настройки → Приложения → Управление приложениями → Родительский контроль → Автозапуск** — включить
- **Настройки → Батарея → Без ограничений**

## Шаг 8: Привязка устройства

1. Запустите бэкенд-сервер:
   ```bash
   docker compose up -d
   ```

2. Создайте аккаунт родителя и получите **6-значный код привязки** через API:
   ```bash
   # Регистрация
   curl -X POST http://localhost:8000/api/v1/auth/register \
     -H "Content-Type: application/json" \
     -d '{"email": "parent@example.com", "password": "your_password", "full_name": "Parent"}'
   
   # Вход
   curl -X POST http://localhost:8000/api/v1/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email": "parent@example.com", "password": "your_password"}'
   
   # Создать код привязки (используйте токен из ответа login)
   curl -X POST http://localhost:8000/api/v1/devices/pairing-code \
     -H "Authorization: Bearer ВАШ_ТОКЕН"
   ```

3. В приложении на телефоне введите полученный 6-значный код
4. Нажмите «Привязать»
5. Готово! Мониторинг начнётся автоматически

## Устранение проблем

### Gradle sync failed
- Убедитесь, что установлен Android SDK 35
- Проверьте интернет-соединение
- **File → Invalidate Caches → Restart**

### APK не устанавливается
- Разрешите установку из неизвестных источников
- Удалите старую версию приложения перед установкой

### Приложение не подключается к серверу
- Проверьте что сервер запущен (`docker compose up -d`)
- Убедитесь что IP адрес в настройках приложения правильный
- Телефон и сервер должны быть в одной сети (или сервер должен быть доступен из интернета)

### Синхронизация не работает
- Проверьте все разрешения (Шаг 7)
- Убедитесь что батарейные оптимизации отключены
- На Xiaomi/Samsung включите автозапуск

### WebSocket отключается
- Проверьте стабильность интернета
- Приложение автоматически переподключается каждые 5 секунд
